# 日本音声作品（ASMR/Voice Drama）翻译与润色指南

本指南定义了日语成人音声、ASMR 与广播剧翻译成中文时的核心原则、风格规范与格式要求。

---

## 1. 核心格式规范（绝对禁止破环时间轴）

1. **严格 1:1 行对齐**：
   - 每行日文原稿对应且仅对应一行中文翻译。
   - 严禁擅自合并两行或将一行拆分成两行，否则会导致 LRC 字幕与播放器时间轴彻底脱节。
2. **符号与氛围保留**：
   - 保留台词中的情绪符号：`♡`、`♥`、`…`、`～`、`！`、`？`。
   - 保留动作与生理拟音标记：例如 `（喘息）`、`（咽口水）`、`（轻笑）`、`（抽泣）`、`（娇喘）`。

---

## 2. 角色人设与语调适配（Persona Alignment）

音声作品的魅力核心在于声优的声线与人设氛围，翻译时必须根据作品设定调整用词语气：

| 人设类型 | 日文特征词 | 中文语气倾向 | 翻译示例 |
| :--- | :--- | :--- | :--- |
| **小恶魔 / 雌小鬼** | ざぁこ、おじさん、生意気 | 挑衅、戏谑、轻浮、带着嘲弄笑意 | 「おじさん、もう限界？ざぁこ♡」→ “大叔，这就到极限了吗？真没用呢♡” |
| **痴女 / 欲求不满** | 我慢できない、もっと、いっぱい | 迫切、渴求、喘息浓重、直白大胆 | 「もっと奥まで…全部注ぎ込んで」→ “再到最里面去…把全部都灌进来…” |
| **温存 / 幼驯染 / 姐姐** | 大丈夫だよ、よしよし、甘えて | 治愈、宠溺、柔和、耳语呢喃 | 「いい子いい子…お姉ちゃんに全部任せてね」→ “好乖好乖…全都交给姐姐吧” |
| **羞涩 / 纯情少女** | 恥ずかしい、見ないで、でも… | 犹豫、吞吞吐吐、受刺激时的轻呼 | 「そんなに見られたら…恥ずかしいよ…」→ “被这样一直盯着看…太害羞了啦…” |
| **快感沦陷 / 坏掉** | 頭真っ白、おかしくなる、イっちゃう | 意识恍惚、断续、语无伦次、理智瓦解 | 「あぁっ…もうダメ…頭変になっちゃう…！」→ “啊啊…不行了…脑子要变得奇怪了…！” |

---

## 3. 口语化与去机翻味（Natural Colloquial Phrasing）

- **拒绝生硬直译**：
  - ❌ 「私のオナニーを見てください」→ “请看我的自慰。”
  - ✔️ “看着我……自己玩弄身体的样子……”
  - ❌ 「気持ちよすぎておかしくなりそうです」→ “因为太舒服似乎要变得奇怪了。”
  - ✔️ “太舒服了……整个人都要坏掉了……！”
- **隐私部位与动作的本土化润色**：
  - `ちんぽ / 肉棒`：肉棒、大肉棒、坏东西、下面（依纯情/下流语境选用）
  - `アソコ / お股`：私处、下面、敏感的地方
  - `中出し`：内射、全都射在里面
  - `イく`：要去了、要到了、要高潮了
  - `ビクビクしてる`：一跳一跳的、在剧烈抽搐

---

## 4. 语气词与拟声过滤规范

1. **纯填充字过滤**：
   - 去除中文中多余的无意义口吃填充词（如连续孤立出现的“嗯、啊、呃”）。
   - 保留带有情绪反应的叹词（如“呜呜……”、“哈啊……”、“哼哼~”）。
2. **疑问语气保留**：
   - 如「ん？どうしたの？」必须保留疑问句首的“嗯？怎么啦？”。
